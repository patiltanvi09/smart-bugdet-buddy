# Smart Budget Buddy

Smart Budget Buddy is a responsive personal finance management web application that helps users track expenses, manage budgets, and improve financial planning.

## 🚀 Live Demo
https://smart-budget-buddy-ppf.netlify.app/

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Responsive Design
- Netlify

## ✨ Features
- Expense Tracking
- Budget Planning
- Savings Monitoring
- Interactive UI
- Mobile Responsive Design

## 📌 Purpose
This project was built to improve my frontend development skills by creating a real-world finance management application.
